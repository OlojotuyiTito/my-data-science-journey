Today I learnt about __comparison operators__ and __Boolean operators__ in Python.

Comparison operators are operators we use to find the relationship between values.

For example:
```python
x = 53
y = -9

print(x < y)
print(x <= y)
print(x > y)
print(x >= y)
print(x == y)
print(x != y)
```

Boolean operators are operators ....

For example:
```python
x = True
y = False

print(x and y)
print(y or x)
print(not y)
print(not x)
```

Using Boolean operators in NumPy:
```python
import numpy as np
np.logical_and(my_house > 18, my_house < 23)\
np.logial_or(attended_lecture == 1, or is_in_sick_bay == True)
np.logical_not(is_insane)
```
